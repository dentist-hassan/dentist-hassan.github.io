# Hassan Abou Hussien | Multidisciplinary Portfolio V3

A static, responsive English portfolio website built with HTML, CSS, and vanilla JavaScript. No build step, API key, or account required.

## Run locally
Open `index.html` in a browser. Keep the `assets/` folder and `data.js`, `styles.css`, `script.js` in the same folder.

## Publish to GitHub Pages
1. Make a new **public** repository only when ready to publish these materials openly.
2. Upload the complete folder contents to the repository root.
3. Go to Settings → Pages → Deploy from branch → `main` / root.
4. Wait for Pages to provide the site URL and open it to test.

**Privacy note:** Clinical case images and certificate images are public if you publish the site. Review ownership, permissions and visible patient details before publishing. No police-clearance document, IDs, or other identity documents are included. The healthcare unit appreciation certificate is included; review it before publishing.

## Update content
Edit `index.html` for text and experience; edit `data.js` for certificates/cases. Images live under `assets/`.

## Technical notes
- Portfolio case images are rendered from supplied PDF case pages, allowing original framing to remain intact.
- Certificates are page images sourced from supplied PDF certificate compilations.
- Google Fonts are optional; the fallback font stack works without network access.
- A curated public-facing PDF profile is included, rather than the NHS profile printout containing personal data.
